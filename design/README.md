# Bold Civic design

Neerdhara uses a high-clarity civic interface made for field work, outdoor glare and multilingual use. The style
combines practical Material interaction patterns with crisp neubrutal borders and hard shadows.

## Core colours

| Name | Hex | Use |
| --- | --- | --- |
| River Teal | `#0E7C86` | Primary actions and navigation |
| Ink | `#102A43` | Text, icons, borders and hard shadows |
| Teal Accent | `#4FC3CB` | Active telemetry and focus accents |
| Paper | `#FFFFFF` | Cards and readable content surfaces |
| Mist | `#F3F6F8` | Low-glare page background |
| Muted Text | `#52667A` | Secondary information |
| Normal | `#138A43` on `#DFF3E6` | Healthy operation |
| Needs Cleaning | `#996B00` on `#FFE7A3` | Maintenance warning |
| Overflow Risk | `#C8102E` on `#FFE1E5` | Critical action |
| Flood Mode | `#1D5FD1` on `#DCE7FB` | Flood response |
| Offline | `#5F6B7A` on `#E6EAEE` | No recent reading |

## Type and structure

- **Epilogue:** strong headings and operational metrics.
- **Noto Sans / Noto Sans Devanagari:** body copy, labels and Hindi text.
- Cards use visible borders, rounded corners and deliberate spacing rather than faint shadows.
- Touch targets are at least 48 dp on mobile; field actions are larger where possible.

## Status is never colour alone

- Normal: circle + check + word.
- Needs cleaning: triangle + warning + word.
- Overflow risk: octagon + hazard mark + word.
- Flood mode: framed waves + word.
- Offline: dashed circle + word.
- Pending: hourglass + word.

The interfaces support English and Hindi, visible keyboard focus on web, semantic labels, readable contrast and
layouts tested at increased text size.
